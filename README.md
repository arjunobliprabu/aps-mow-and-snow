# AP's Mow and Snow

A single-file web app for a seasonal lawn mowing and snow removal business — built by Arjun ObliPrabu.

## What it does
- Browse Spring–Fall and Winter services with pricing
- Customer sign up / sign in (email + password + address)
- Real booking calendar with day/time selection
- Cart, checkout, and a demo payment flow (no real charges)
- Admin dashboard (bookings, revenue, customers, cancel bookings)
- Light / dark mode

## How to use it
Just open `index.html` in any web browser — no installation or build step needed.

You can also turn on **GitHub Pages** for this repo (Settings → Pages → deploy from the `main` branch) to get a live shareable link.

## Note on security
This app runs entirely in the browser with no backend server, so account passwords and the admin login are stored in the page's own code / the browser's local storage — not securely encrypted. This is fine for a school project or demo, but shouldn't be used with real, important passwords or real customer payment data.
